Le moteur 3D ne s’est pas chargé. Ce fichier utilise Three.js depuis Internet et doit être ouvert dans un vrai navigateur, via un serveur web, et non dans l’aperçu de fichiers du téléphone.

Pour le lancer :
1. Place le fichier dans un dépôt GitHub.
2. Active Settings → Pages sur la branche et le dossier contenant le HTML.
3. Ouvre l’adresse https://ton-compte.github.io/ton-depot/ dans Chrome.

Vérifie aussi que la connexion Internet fonctionne. Si l’erreur persiste sur le site hébergé, le CDN peut être bloqué ou indisponible.
